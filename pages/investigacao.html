Algumas palavras podem ser novas? Veja um guia rápido.
Falha de segurança
Um erro que pode deixar alguém acessar ou alterar algo sem autorização.
CVE
Um número de identificação usado para encontrar o aviso de uma falha específica.
CVSS
Uma escala que estima a gravidade técnica. Não diz, por si só, se alguém foi atacado.
Crítica ou alta gravidade
Uma avaliação do risco possível. Não significa que alguém já invadiu um computador.
Exploração
Uma tentativa de usar a falha para causar um efeito. Isso não confirma, por si só, que alguém conseguiu invadir.
Comprometimento
Quando alguém consegue acesso ou controle que não deveria ter.
Engenharia social
Quando o atacante engana uma pessoa para conseguir acesso, credenciais ou executar um programa malicioso.
DDoS
Grande volume de tráfego distribuído para tentar deixar um serviço indisponível.
Runtime
O programa que permite que outro programa seja executado, como Node.js ou PHP.
Certificado digital
Uma credencial que ajuda o navegador a conferir com quem está se conectando.
Cadeia de fornecimento
O conjunto de programas, bibliotecas e atualizações usados para criar um serviço.
Firmware
O programa básico que vem dentro de um aparelho e o ajuda a iniciar.
Execução remota de código
Quando uma falha pode permitir que alguém rode instruções em outro computador pela rede.

O que significa “crítica”?

É uma avaliação do dano que a falha poderia causar. Uma nota alta não prova que alguém usou a falha para atacar. As escalas também podem variar entre fabricantes.
